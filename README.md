## How to read these notes

Each item is marked as one of:

- **Agreed** — confirmed by both sides in the project email exchange.
- **Proposed** — suggested by Nikhil, The Maestro, or Boardy; not a settled decision.
- **Open** — requires a decision or further evidence.

The email exchange is not evidence that a trigger, parser, matching routine, timeout service, or other integration has been implemented.
